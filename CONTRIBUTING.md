# Contributing

Thanks for helping. This list is for scientists, educators and scientific animators, so every entry should help someone make or understand a molecular or cellular animation.

## Adding an entry

- Open a pull request that adds one entry per line in the right section.
- Use this format: `[Name](https://link) - Short neutral description.`
- Describe what the resource does and any important limit, such as a license or price model. Leave out marketing words.
- Link to the project's own page, not a review or a reseller.
- Check that the link works and that the project is still available.
- Keep the README and `docs/index.html` in sync. The site shows the same list.

## What fits

- Software, add-ons, data sources, tutorials, communities, papers and talks about molecular, cellular or medical animation and visualization.
- Commercial tools are welcome when they are genuinely useful. Disclose any affiliation in the pull request.

## What does not fit

- Duplicate entries or several links to the same project.
- Projects that are abandoned or whose links no longer work.
- Paywalled downloads of other people's work.

## Fixing an entry

If a link is broken, a price or license changed or a description is wrong, open an issue or a pull request with a link to the source.
